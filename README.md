# Proyecto Blog Django

Este proyecto es un blog básico con herencia de plantillas y formularios para insertar y buscar datos.

## Funcionalidades

1. **Inicio**: Página principal (`/`)
2. **Crear Autor**: Formulario para agregar autores (`/autor/`)
3. **Crear Categoría**: Formulario para agregar categorías (`/categoria/`)
4. **Crear Post**: Formulario para agregar posts (`/post/`)
5. **Buscar Post**: Formulario para buscar posts por título (`/buscar/`)

## Cómo probar

1. Ejecutá `python manage.py runserver`
2. Accedé a `http://localhost:8000/`
3. Navegá por las opciones del menú para probar cada funcionalidad

## Requisitos

- Python 3.x
- Django 4.x
